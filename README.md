# Keep 运动主题网页学习展示

冰屋、冰块、粒子字形与页面内介绍组成的单页作品。支持独立冰块点击、粒子形态切换及声音控制。

## 部署

仓库 Settings → Pages → Source 选择 GitHub Actions。向 main 推送后运行 Deploy website to GitHub Pages。

## 来源与用途

这是非商业学生学习展示。场景引擎及原始视觉素材来自 Igloo Inc.（https://www.igloo.inc/），Keep 字样及品牌归其权利人所有。运动文案、字形体积和点击适配为本项目修改。资源未取得统一开源许可，本仓库不授予第三方资源的再分发或商业使用许可。

已完成线上加载、两个不同冰块的真实点击、滚动跨场景及 Keep 粒子形态切换验收。全部 70 个冰块使用独立几何命中检测；未逐一人工点击全部冰块。
